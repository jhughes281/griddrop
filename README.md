# GridDrop

**The complex is already mapped.**

Interactive concept prototype of a crowd-built delivery map for apartment complexes — unit numbers pinned to the right building, floor levels called out, and gate codes on screen before the driver is off the main road. Designed by a working delivery driver.

- **Live demo:** https://jhughes281.github.io/griddrop/
- **The pitch:** https://jhughes281.github.io/griddrop/pitch.html

## What works in the demo

- **Network** — browse nearby complexes, mapped and unmapped
- **Route** — access info (gate code, door rules, drop-off policy), type unit numbers to pin them to buildings with floor callouts, live site map
- **Guide** — stop-by-stop guided run with simulated GPS
- **Map one** — the five-minute contribution flow: snap the entrance site-map sign, confirm the layout, set floors per building, add access info and a driver tip, publish. The published complex uses exactly what you entered.

All data is demo data. No real gate codes or property information appear anywhere.

Single-file static app (`index.html`) — no build step, no dependencies. Open it or serve the folder.
